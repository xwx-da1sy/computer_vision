# 任务 1-5：图像处理入门与一维条形码识别

> 报告草稿。请按课程的实践报告模板填写学校、专业、班级、姓名及提交时间，并根据自己的理解检查、补充实验过程和截图。样本是公开的实物照片，并非本人拍摄；具体提交格式以老师通知为准。

## 实验目的

学习使用 Python 读取图片，了解灰度化、直方图均衡化、均值滤波和腐蚀等操作，完成对照片中一维条码的定位、解码和结果展示。

## 实验环境

- Windows，Conda 环境 `dl-study`。
- Python，OpenCV 5.0.0，NumPy，ZXing-C++ Python 包 `zxing-cpp` 3.1.1。
- 识别代码：`02_detection.py`；预处理实验代码：`03_preprocessing.py`。

## 实现方法

1. 指定图片路径，用 NumPy 读取文件字节，并用 OpenCV 将字节解码成彩色图像数组；检查文件不存在或无法解码的情况。
2. 使用 ZXing-C++ 的一维码读取功能，从原图尝试定位和解码。如果原图未读出任何条码，则依次尝试灰度图、灰度图均衡化版本、灰度图 3×3 均值滤波版本；均衡化和滤波并非串联。
3. 使用返回的条码位置在原图副本上画框。输出条码类型、内容、使用的方法，并保存标框图片和文本结果。

OpenCV 负责读取、图像处理和绘图；ZXing-C++ 提供现成的条码定位与解码算法。此实验没有从零实现 EAN 编码解析算法，也没有训练深度学习模型。

## 实验结果

使用 5 张公开实物照片，共包含 6 个预期 EAN-13 条码。程序从原图读出以下内容，并与图片印刷数字或样本附带标注一致：

| 样本 | 读出内容 |
|---|---|
| 书籍 A | 9780307951526 |
| 书籍 B | 9784873117980；1923055034006 |
| 罐装商品 | 8413000065504 |
| 柔性包装 | 8480010001136 |
| 反光包装 | 5201815331227 |

程序另外验证了空白图片、无法解码的文件和不存在的路径：分别报告未读出或输入错误。截图可从 `一维条码结果/` 中选择本次实际运行结果，确保截图与报告内容一致。

## 预处理观察

另行使用 `03_preprocessing.py` 比较原图、灰度图以及连续的全局直方图均衡化、3×3 均值滤波和 3×3 灰度腐蚀。五张图的原图及灰度图均读出预期值；连续处理至均衡化阶段时两张图未读出，处理至腐蚀阶段时五张均未读出。各步骤在此实验中是连续叠加的，不能单独归因于腐蚀。实验记录、图片及限制见 `预处理实验记录.md`。

## 局限与后续改进

- 这五张图不是随机抽样，不足以衡量现实条件下的总体准确率。实际测试仍需覆盖不同光照、模糊、角度、距离、背景和码制。
- 程序在某个版本读到至少一个条码后即停止；如果一张图有多个条码而只读出一部分，其他版本不会继续尝试，可能遗漏。
- ZXing 返回空列表只表示没有成功读出的条码，不能据此区分没有定位和定位后未成功解码。
- 未来可分别比较单项预处理及不同解码器，并用自己拍摄的商品照片扩大测试。
