# 任务 1-6：PyTorch CIFAR-10 分类

## 与已有学习的关系

本机 `Deep Learning/vision_transformer_practice` 已有 CIFAR-10 的 Tiny ViT 和 CNN 实验及数据，本任务使用小型 CNN 重新展示数据、训练、验证和测试的完整链条。有关 CIFAR-10 和基本训练方法可参考 [PyTorch 官方分类教程](https://docs.pytorch.org/tutorials/beginner/blitz/cifar10_tutorial.html)。老师指定的[参考视频](https://www.bilibili.com/video/BV1R2Htz3Ej2/)可用于对照课程要求。

本机 `dl-study` 环境已安装 PyTorch、torchvision，并检测到 NVIDIA GPU。无需重装；运行时用 `conda run` 激活完整环境，直接调用环境内 Python 在本机曾出现 cuDNN 动态库加载失败。训练脚本默认读取已有数据目录，未找到数据时可使用 `--data` 指定目录并加 `--download`。

## 流程

- CIFAR-10 为十类、32×32 RGB 图像。官方训练集 50,000 张，测试集 10,000 张；本实验从训练集以固定种子随机留出 5,000 张作为验证集，剩余 45,000 张训练。测试集只在选好模型后使用。
- 输入转为张量并按 `(x - 0.5) / 0.5` 归一化。两层卷积 + ReLU + 池化提取特征，再用全连接层输出 10 个类别的 logits。
- 交叉熵接收 logits 和整数标签；Adam 更新参数。每个 epoch 统计训练损失与验证损失、准确率，按验证准确率保存最佳模型，最后评估测试集。
- 分类准确率 = 正确数量 / 样本数量。测试集分数不是训练集分数，也不是对其他数据的性能保证。种子、GPU 算子与软件版本可能影响复现。

## 运行

在 `D:\computer_vision` 的 PowerShell 中：

```powershell
conda run --no-capture-output -n dl-study python .\任务1-6_CIFAR10\train.py --epochs 5
```

指定其他数据目录并允许下载：

```powershell
conda run --no-capture-output -n dl-study python .\任务1-6_CIFAR10\train.py --data .\data --download --epochs 5
```

输出 `output/metrics.json` 包含每轮训练及验证结果、测试集准确率和各类准确率；`output/best_model.pt` 是验证集最优权重。重复运行会覆盖它们。若在 Notebook 中运行，请选择 `dl-study` 内核并核对 `sys.executable`。

## 本次运行结果（2026-10-29）

使用 PyTorch 2.10.0、CUDA、种子 42、批量大小 128、Adam 学习率 0.001，训练 5 轮。验证准确率从第 1 轮的 57.18% 上升至第 5 轮的 71.54%；选择验证准确率最高的权重后，测试集正确 7,105 / 10,000，准确率 **71.05%**。模型、数据划分、每轮损失以及各类测试结果均记录在输出文件中。这是入门基线，不能直接与配置不同的既有实验公平比较。
